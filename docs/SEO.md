# Поисковая оптимизация: что сделано и что делать дальше

Сайт готов к индексации Яндексом и Google: техническая часть в коде, дальше
нужны действия в кабинетах вебмастера и работа с содержанием.

## Что уже в коде

| Что | Где | Зачем |
|---|---|---|
| `robots.txt` | `app/robots.ts` | закрывает кабинет, админку и API, указывает карту сайта |
| `sitemap.xml` | `app/sitemap.ts` | перечисляет публичные страницы и страницы выпусков |
| Канонические адреса | `lib/seo.ts`, `pageMetadata()` | убирает дубли страниц с параметрами |
| Заголовки и описания | каждая страница | то, что видно в выдаче |
| Микроразметка организации и сайта | `app/layout.tsx` | карточка компании в поиске |
| Микроразметка программы с ценами | главная, тарифы, для бизнеса | строка «от 390 ₽» в выдаче |
| Вопросы и ответы | главная, тарифы, поддержка, пробный период | блок «часто спрашивают» |
| Хлебные крошки | внутренние страницы | понятный путь вместо длинного адреса |
| Подтверждение прав | переменные окружения | Вебмастер и Search Console |
| Счётчик Метрики | `components/seo/metrika.tsx` | статистика, подключается при заданном номере |

Посадочные страницы под запросы: главная («удалённый доступ к компьютеру»),
`/tarify` («цена, стоимость»), `/dlya-biznesa` («для компании, для бизнеса»),
`/probnyy-period` («пробный период, тестовый доступ»), `/sravnenie`
(«сколько стоит, дешевле»), `/skachat` («скачать программу»).

## Что сделать после развёртывания

1. **Яндекс.Вебмастер** — добавьте сайт, возьмите значение мета-тега и
   положите в `REMIT_YANDEX_VERIFICATION`, пересоздайте контейнер `web`.
   Затем: отправьте `sitemap.xml`, задайте регион («Москва» или ваш),
   заполните «Товары и цены», проверьте «Диагностику».
2. **Google Search Console** — то же самое через
   `REMIT_GOOGLE_VERIFICATION`, добавьте карту сайта, проверьте отчёт
   «Страницы».
3. **Яндекс.Метрика** — создайте счётчик, номер в `REMIT_YANDEX_METRIKA_ID`.
   Настройте цели: отправка заявки на пробный период, регистрация, переход к
   оплате.
4. **Яндекс.Бизнес** — карточка организации даёт региональную привязку и
   показ в картах; для сервисов это заметно помогает по запросам с городом.
5. **Скорость** — проверьте главную в PageSpeed Insights. Сайт статический,
   но большие картинки в будущем легко всё испортят.

## Что делать дальше с содержанием

Техническая часть даёт возможность ранжироваться, а трафик приносят тексты.
Порядок по убыванию отдачи:

1. **Страницы под задачи, а не под продукт.** «Удалённое подключение к кассе»,
   «Помощь бухгалтеру с 1С удалённо», «Доступ к рабочему компьютеру из дома» —
   такие запросы конкретнее и конкурентнее по конверсии.
2. **Сравнения и инструкции.** «Как подключиться к компьютеру через интернет»,
   «Что делать, если чёрный экран при удалённом подключении» — приводят людей
   из поиска на этапе проблемы.
3. **Страница цен без мелкого шрифта.** У конкурентов часто прячут лимиты;
   честная таблица хорошо работает и для людей, и для поведенческих факторов.
4. **Отзывы и кейсы.** Реальные истории внедрения с цифрами: сколько рабочих
   мест, сколько сэкономили.

Не покупайте ссылки и не размещайте скрытый текст: Яндекс за это понижает
сайты целиком, а восстановление занимает месяцы.

## Проверка после изменений

```bash
curl -s https://remit.su/robots.txt
curl -s https://remit.su/sitemap.xml | head -20
curl -s https://remit.su/ | grep -o 'application/ld+json' | wc -l
```

Микроразметку удобно проверять валидатором Яндекса и Rich Results Test у
Google: они покажут, какие блоки поиск сможет использовать.
