# Веб-клиент: откуда он и почему не новее

Веб-клиент на `/webclient` — Flutter-сборка RustDesk 1.1.10 из
[lejianwen/rustdesk-api](https://github.com/lejianwen/rustdesk-api/tree/master/resources/web)
с нашими правками (без аналитики Firebase и загрузки из Google, отметка
«бета»). JS-ядро с исходниками лежит в `public/webclient/js`; лицензия и
ссылки — на странице `/dokumenty/licenzii`.

## Проверено в сентябре 2026: свежее открытой сборки нет

- **Официальный веб-клиент RustDesk v2** (web.rustdesk.com) — закрытый: в
  репозитории от него только `flutter/web/v2/README.md`. Использовать его
  копии (они встречаются в сборках панелей) нельзя — нет лицензии.
- **Открытый веб-клиент v1** жил в `flutter/web/js`. 22.06.2024 (коммит
  `41a20b50`, RustDesk 1.2.6) его отделили с пометкой «v1 is not compatible
  with current Flutter source code» и отключили сборку, 01.07.2025 удалили.
- **Последний открытый коммит (`3742b51d`, 1.2.6)** собирается (Flutter
  3.19.6, JS-ядро на vite 2.8), но не работает: Dart-мост веб-версии
  переписывался под закрытое ядро v2, в нём 158 методов бросают
  `UnimplementedError`, главный экран падает при запуске
  (`mainGetAppNameSync`, `mainIsOptionFixed`, ошибки вёрстки). Довести его —
  значит самим дописать мост к ядру v1, причём без официальной поддержки.
- Форки вроде MonsieurBiche/rustdesk-web-client и pmietlicki/rustdesk-web-client
  основаны на том же старом v1 и новее нашей сборки по возможностям не
  делают.

Итог: текущая сборка — самая свежая из рабочих открытых. Когда появится
открытая альтернатива (или RustDesk вернёт открытый веб-клиент), заменить её
несложно: сайт отдаёт клиенту настройки через `/webclient-config/index.js`,
`/api/server-config` и `/api/shared-peer` (гостевые ссылки), а подключение
идёт через hbbs/hbbr по WebSocket (порты 21118/21119, в проде — wss через
nginx).

Для постоянной работы в кабинете и на странице веб-клиента советуем
приложение: оно быстрее, поддерживает входящие подключения и всё остальное,
чего в браузере нет.
